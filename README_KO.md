> ⚠ **서버 전용 모드** — **PlanetEarth Server (`planetearth.kr`)** 에서만 작동합니다. 다른 서버에서는 아무 기능도 작동하지 않습니다.

PlanetEarth 서버의 상자 GUI 기반 악기 (`악기 - 하프`, `악기 - 베이스(드럼)` 등) 를 **키보드** 또는 **MIDI 장치** 로 연주할 수 있게 해주는 클라이언트용 Fabric 모드. 키를 누르면 모드가 해당 슬롯을 클릭하고, 서버 플러그인이 음을 재생합니다.

## 주요 기능

- **키 입력 → 슬롯 클릭** (상자 제목이 `음악` 또는 `악기` 로 시작하면 자동 작동)
- **음량 조절** *(v5.3.0)* — 방향키 / GUI 밖 클릭 / `Tab + 숫자` 로 `/instruments` 명령 전송
- **MIDI 입력 지원** *(v4.0.0)* — USB MIDI 키보드 / 패드 장치 연결 후 직접 연주 가능
- **MIDI 이조** *(v5.1.0)* — 입력 음을 ±24 반음 (±2 옥타브) 이동, 메뉴 상단에서 조절
- **옥타브 접기** *(v5.2.0)* — 이조로 F#2~F#6 범위를 벗어난 음을 버리지 않고 옥타브 단위로 접어 재생
- **음별 보조 키** *(v4.2.0)* — 한 음에 서로 다른 키 2개를 지정
- **통계 화면** *(v4.1.0)* — 분당 입력 꺾은선 그래프, TOP 5 음, common vs drum preset 비율, 세션 통계
- **2 개 preset, 상자 제목에 따라 자동 선택**
  - `공통` — 49 음 (F#2 ~ F#6) — 일반 멜로디 악기용
  - `드럼` — 12 음 (베이스 / 하이햇 / 스네어 / 심벌 × 상중하) — `(드럼)` 상자용
- **자동 매핑** — 상자 한 번 열고 메뉴에서 "자동 매핑" 클릭 → 해당 상자 실제 슬롯 배치에 맞게 자동 정렬 (아이템 이름 매칭, 실패 시 인덱스 기반 폴백)
- **Space + 키 조합 modifier** *(v3.12.0)* — 흰건반은 키 단독, 검은건반은 `Space + 같은 키`
- **인게임 키 재설정** — 좌클릭 변경, 우클릭 미설정, ESC 기본값
- **조합키 10종** *(v5.3.0)* — `Shift` `Ctrl` `Alt` `Win` `Space` `Tab` `CapsLock` `Enter` `\` `Backspace`
- **충돌 검사** + 빨간 강조 (중복 키 거부)
- **키 자동 반복 방지** *(v4.0.3)* — 꾹 눌러도 1번만 클릭
- **음별 사용 횟수** (× N) 매핑 표 우측에 표시
- **preset 탭** (공통 / 드럼 / 통합 설정)
- **H2 영속 저장** (shade — Lunar Client / Ichor 호환)
- **클릭 옵션** — PICKUP / QUICK_MOVE / SWAP / ... + 좌/우/중클릭 (고급 설정에서 변경)
- **한국어 + 영어** 지원

## 사용 방법

1. 자신의 Minecraft 버전에 맞는 jar 설치 ([호환](#호환) 표 참고) — Fabric Loader + Fabric API 필수
2. **PlanetEarth 서버** 접속 (`planetearth.kr`)
3. 음악 상자 (예: `악기 - 하프`) 열기 → 모드가 슬롯 자동 캐시
4. **`\`** (backslash, 메뉴 기본 키) 누르기 → Musix 메뉴 열림
5. **자동 매핑** 클릭 → 현재 상자에 맞게 슬롯 정렬
6. 다시 상자 열고 매핑된 키 누르면 음 재생
7. 다른 악기로? 자동 매핑 다시
8. **음량**: 상자가 열린 상태에서 방향키 `↑`/`↓`, 또는 `Tab + 1~9,0` 으로 정확한 값 지정
9. **통계**: 메뉴 → **통계** 버튼 · **MIDI**: 메뉴 → **고급 설정** → **MIDI 입력**

## 기본 키 배치 (공통 preset, 49 음 — 본음 + 반음)

본음은 키 단독, 반음 (`#`) 은 **`Space + 같은 키`** 조합으로 재생됩니다.

| 줄    | 키                          | 본음 (단독)      | 반음 (Space + 키)              |
|-------|-----------------------------|------------------|--------------------------------|
| 1 줄  | `` ` 1 2 3 ``              | G2 → B2          | F#2, G#2, A#2                  |
| Q 줄  | `Q W E R U I O`            | C3 → B3          | C#3, D#3, F#3, G#3, A#3        |
| A 줄  | `A S D F J K L`            | C4 → B4          | C#4, D#4, F#4, G#4, A#4        |
| Z 줄  | `Z X C V M , .`            | C5 → B5          | C#5, D#5, F#5, G#5, A#5        |
| 추가  | `7 8 9 0`                  | C6 → F6          | C#6, D#6, F#6                  |

모든 키는 메뉴에서 자유롭게 재설정 가능합니다 (좌클릭으로 행 선택 후 새 키 입력).

## 드럼 preset (제목에 `(드럼)` 포함 시 자동 활성)

12 음 / 4 행. 상자 열림 시 아이템 이름 매칭으로 슬롯 자동 정렬.

- `1 2 3` → 베이스 낮은음 / 중간음 / 높은음
- `Q W E` → 하이햇 낮은음 / 중간음 / 높은음
- `A S D` → 스네어 낮은음 / 중간음 / 높은음
- `Z X C` → 심벌 낮은음 / 중간음 / 높은음

차단 슬롯 (매핑 X): `6, 19, 45, 53` — 서버 GUI 네비게이션 슬롯

## 음량 조절 *(v5.3.0+)*

**악기 상자가 열려 있을 때만** 작동합니다. **두 가지 방식이 섞여 있습니다:**

| 입력 | 동작 | 방식 |
|---|---|---|
| `↑` (위 방향키) | 음량 올리기 | GUI 밖 **좌클릭** 패킷 전송 (슬롯 `-999`) |
| `↓` (아래 방향키) | 음량 내리기 | GUI 밖 **우클릭** 패킷 전송 (슬롯 `-999`) |
| GUI **바깥** 좌 / 우클릭 | 음량 올리기 / 내리기 | 마크 기본 동작 그대로 통과 |
| `Tab + 1` ~ `Tab + 9`, `Tab + 0` | 음량 1~10 정확히 지정 | `/instruments <n>` 명령 전송 |

서버가 상자 GUI 밖 클릭을 음량 조절로 처리하므로, 방향키는 **커서를 옮기지 않고 같은 패킷만** 보냅니다.
`/instruments` 명령을 쓰는 건 `Tab + 숫자` 뿐입니다.

- **악기 상자를 열면 `/instruments 8` 로 음량 8 이 됩니다.** 모드가 서버의 현재 값을 읽을 수 없기 때문입니다.
- **9~10 은 소리가 커지는 게 아니라 들리는 거리가 멀어집니다.** 실질 최대 음량은 8 입니다.
- 0.1 초 쿨다운. **방향키를 꾹 누르면 0.1 초마다 연속 조절됩니다.**
- 커서에 아이템을 들고 있으면 방향키 조절을 건너뜁니다 — 슬롯 `-999` 클릭이 아이템을 버리기 때문입니다.
- 메뉴의 "현재 음량" 은 **추정치** 입니다. 실제 값은 서버가 관리하므로 1↔10 순환 여부도 서버 동작을 따릅니다.
- 12 개 키 모두 메뉴의 **통합 설정** 탭에서 재설정 가능합니다.

## MIDI 입력 *(v4.0.0+)*

- **메뉴 → 고급 설정 → MIDI 입력** — 연결된 MIDI 장치 목록 스캔, 클릭으로 연결
- 다음 실행 시 같은 장치가 여전히 연결되어 있으면 자동 재연결
- 장치 스캔 / 연결 비동기 처리 — 클라이언트 멈춤 방지
- 키보드 입력과 병행 사용 가능

### 이조 *(v5.1.0+)* 와 옥타브 접기 *(v5.2.0+)*

- 메뉴 상단 `[-12] [-1] (이조) [+1] [+12]` — 입력 MIDI 음을 **±24 반음** 까지 이동
- **옥타브 접기** (기본 ON, 고급 설정에서 토글) — 이조 후 연주 가능 범위 (F#2~F#6) 를 벗어난 음을
  그냥 버리지 않고 옥타브 단위로 접어서 재생

## 통계 화면 *(v4.1.0+)*

- **세션 정보**: 시작 시각, 경과 시간, 총 음 입력, 분당 평균 / 현재 분 입력, 마지막 음
- **꺾은선 그래프**: 최근 60 분 분당 입력 추이 (Y 축 자동 스케일)
- **TOP 5 음**: 가장 많이 누른 음 5 개의 막대 차트
- **Preset 비율**: common vs drum 백분율 + 절대 수
- **초기화 버튼**: 모든 카운터 리셋하고 세션 타이머 재시작

## 빌드

[Stonecutter](https://stonecutter.kikugie.dev/) 기반 멀티버전. 전 버전 일괄 빌드 (JDK 21 필요):

```sh
./gradlew chiseledBuild
```

산출물: `versions/<mc>/build/libs/musix-mc<mc>-<version>.jar` (Minecraft 버전마다 1개).
1.20.2–1.20.4 는 Java 17 바이트코드로, 1.20.5+ 는 Java 21 로 컴파일됩니다. `gradle.properties` 에
로컬 `org.gradle.java.home` 이 고정돼 있으니 (PC 마다 경로 조정, 또는 그 줄을 지우고 `JAVA_HOME` 을 JDK 21 로 설정).

GitHub Actions 가 push 마다 전 버전을 빌드하고, `v*` 태그 push 시 Release 에 모두 첨부합니다.
